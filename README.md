# Dipanshu Chaturvedi — 3D Portfolio

Vite + TypeScript + Three.js. Content comes from the resume only.

## Run
npm install
npm run dev      # local dev server
npm run build    # outputs dist/ (deploy to Netlify / GitHub Pages / Vercel)

## Edit
- Content: index.html
- Styles: src/styles.css
- 3D scene, nav, animations: src/main.ts
- Photo and resume PDF: public/ (keep the resume filename or update the two links in index.html)
